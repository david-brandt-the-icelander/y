**Reading the tables.**

- No file is refused, so none is refused for a comment inside an erased production (`strip` refuses those).
- 1067 of 1145 type slots map to the type language (93%); 78 are host text, mostly slices (32), lifetime arguments
  (25) and arrays (10).
- `mut` derived through rustc equals the original `mut` on bindings and `self` in every corpus (221 and 221); no file
  differs from its original in `mut`.
- Check 4 drops all 175 holes and keeps the signatures: every failure is an undetermined hole (57), none was filled by
  `weave`, no other error. 52 are inference failures and 5 are a type rustc chose and the program rejects; 4 sit at
  a site the file never filled.
- Gaps for section 12, from the tables: generic parameters 33 type and 27 lifetime, 34 bounds and 9 `where` clauses
  as host text; associated types 1, `impl Trait` 5, `dyn` 2, bounded types 1; `usize` and `isize` 108 types; `const fn`
  1 and no other function modifier; slices 32, arrays 10, types with lifetime arguments 25; in bodies 725 macro
  invocations (272 `assert_eq!`), 3 with typed tokens that strip does not see, `.unwrap()` 40, `.expect()` 12, `panic!` 1.

**Limits.**

- A hint binds by kind and by its ordinal among the sites of that kind in its function. Adding or removing a site shifts
  every later hint of that kind, and `weave` reports only the hints left without a site (`unbound hint`), not one that
  now sits at a different site. Locals bind by pattern text, with `#2` for a second `let` of the same pattern.
- `weave` reports entries that bind to nothing (`unbound local`, `unbound hint`, `unbound subject`) as warnings and
  counts them in its output and in `.bare-rust-map.json` under `@unbound`; they are not errors.
- The undetermined counts of check 4 are lower bounds: rustc reports where it first needs a type, so several dropped
  holes can give one report.
- A `use` is a subject only when it has a visibility (`<scope>::use <path>`, kind `use`). A comment inside a span that
  strip cuts is not relocated: the file is refused.
