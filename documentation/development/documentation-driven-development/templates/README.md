# Templates

One starting file per document kind in [05](../05-document-taxonomy.md). Copy, fill, delete what does
not apply — an empty section is worse than an absent one, because a reader cannot tell whether it is
empty because there is nothing or because nobody wrote it.

| File | Kind | Perspective |
| --- | --- | --- |
| [feature.md](feature.md) | Vertical feature | Whoever uses the capability |
| [journey.md](journey.md) | User journey | One actor, start to finish |
| [subsystem.md](subsystem.md) | Subsystem / integration | On-call engineer, integrator |
| [component.cs.md](component.cs.md) | Component | Maintainer with the file open |

⚠️ **Unproven.** No document has been written from any of these. Wave 0 converts one of each by hand
before anything is scaled → [06](../06-rollout-plan.md#wave-0).
